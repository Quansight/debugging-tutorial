# Debugging tutorials

Tutorials for debugging native code on Linux and macOS.

Complete the [setup](SETUP.md) before the session.

The [NumPy reference-counting tutorial](debugger-tutorial/README.md) uses debug
Python, SIGUSR1, and an LLDB hardware watchpoint to follow a one-line bug
across the extension/interpreter boundary.

The [Samply profiling tutorial](samply-tutorial/README.md) is under construction.

Commands in `bash` blocks run in your terminal; commands prefixed with
`(lldb)` run at the debugger prompt.
