# NumPy debugging tutorials

Hands-on tutorials for debugging and profiling NumPy's C code. Each
directory is a standalone [pixi](https://pixi.sh) workspace with its own
locked environment. `cd` into one and follow its README.

| Directory                              | Topic                                                   |
|----------------------------------------|---------------------------------------------------------|
| [`gdb-tutorial/`](gdb-tutorial/)       | Debug a real NumPy segfault with gdb (lldb on macOS)    |
| [`samply-tutorial/`](samply-tutorial/) | Profile NumPy with samply *(stub)*                      |

Supported platforms: Linux and macOS.
